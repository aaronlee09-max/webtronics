무선 네트워크 기술

전자 태그
(RFID)

소형 반도체 칩 내장 태그·라벨·카드 등에 저장된 데이터를 무선 주파수로 읽음

교통 카드 · 하이패스 · 상품 정보 인식

와이파이
(WIFI)

랜을 무선화하여 가까운 거리에서 데이터를 주고받음

비용이 저렴하고 전송 속도가 빠름

블루투스
(Bluetooth)

10m 이내에서 무선으로 데이터를 주고받음

무선 이어폰 · 인공지능 스피커 · 페어링

근거리 무선 통신
(NFC)

10cm 내 가까운 거리에서 접촉하지 않고 데이터를 주고받음

비용 지불 · 티켓 발매 · 출입 통제

디스플레이 공유
기술

서로 다른 기기의 화면을 공유

미러링 · 미라캐스트 · DLNA
