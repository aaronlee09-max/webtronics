대규모 데이터를 저장·분석해 숨겨진 가치를 찾는 기술

02

p.58~60

빅데이터 분석

탐색적 데이터 분석으로 문제를 정의하고, 수집·분석·평가한다

1

문제 정의

분석 필요성, 요구 사항, 분석 범위를 파악해 구체적인 목적을 정한다.

2

데이터 수집

목적에 맞는 데이터를 자동 수집기, 인터넷 검색, 설문·실험·관찰로 모은다.

균형 · 개인정보 · 편향성 · 저작권 확인
3

데이터 분석

전처리

평균·중앙값·최빈값을 확인하고 결측치, 중복값, 이상치를 정리한다.

시각화·분석

시간, 관계, 비교 시각화로 흐름·관계·패턴을 찾아 해석한다.

4

공유 및 평가

분석 결과가 의사 결정에 도움을 주는지 검토하고 개선책을 제시한다.

탐색적 데이터 분석(EDA)

데이터를 여러 관점에서 관찰해 구조적 관계를 찾는 분석법

시각화 유형

선그래프·막대그래프·버블 차트·산점도·히트맵·워드 클라우드
